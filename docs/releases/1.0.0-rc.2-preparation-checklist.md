# SwiftAgent 1.0.0-rc.2 Release Checklist

> last-verified: 2026-09-20
>
> This is the final release-preparation checklist. It does not create or move
> a tag and does not authorize a GitHub Release.

## Candidate and anchor

- [x] The immutable `1.0.0-rc.1` annotated tag resolves to
  `d2347f11c6a78f421708e897dae42a51a98d37ea`.
- [x] RC.2 work remains off `main`.
- [x] Production fixes are frozen in source commit `043e3b8` before this
  documentation-only seal. The final candidate is the pushed commit containing
  this checklist; its exact SHA is recorded in the parent project's SAI-073
  release record.
- [x] No RC.1 tag, RC.2 tag, or GitHub Release was moved or created.

## Correctness and safety

- [x] Session startup preparation is bounded by the Run's absolute deadline.
  Projector and token-estimator timeout cannot commit the new input, call a
  Provider, or leak startup identity/journal ownership.
- [x] Caller cancellation remains `CancellationError`, distinct from the typed
  `AgentLoopError.deadlineExceeded`.
- [x] Mutation admission, Evidence, Receipt, Journal schema, reconciliation,
  physical drain, and session identity semantics are unchanged.
- [x] Named preflight deadline regressions are in
  `Tests/AgentCoreTests/AgentModelBindingTests.swift` and indexed in
  `docs/testing-regressions.md`.
- [x] Public API inventory was regenerated with Swift 6.4: 1,759 public
  identifiers and 188 top-level public types, with no precise identifier
  removed from rc.1. See
  `docs/guides/swift-agent-public-api.md`.

## Package gates

- [ ] SwiftAgent package full suite on the final candidate: record the exact
  command, discovered/passed/skipped counts, and exit code in the parent SAI-073
  record.
- [ ] Linux/Docker Noble package and target-isolation gate.
- [ ] Concurrency seal, ExternalClient, DynamicModelRouting, ProviderQualification

  fixture gates.
- [ ] iOS 16 cross-build.
- [ ] Final candidate hosted SwiftAgent CI has three real runner-backed jobs:
  macOS, Linux, and Apple adapter compile.

## Host integration

- [ ] Tingting gitlink points to the exact pushed final SwiftAgent candidate.
- [ ] Otoha focused tests, Tingting macOS build, and Tingting iOS Simulator
  build pass for that gitlink.
- [ ] A fresh recursive clone resolves the parent gitlink and child HEAD to the

  `steps=0` remains `BLOCKED_INFRA`, not pass or code failure.

## Documentation and public surface

- [x] Intermediate `docs/reviews/` materials are removed from the candidate
  tree. Durable contracts live in guides, ADRs, testing docs, release notes,
  or the CHANGELOG; one-time evidence lives in the parent Kanban.
- [x] README navigation, provider guides, acceptance checklist, and testing
  docs contain no links to the removed review tree.
- [x] Stable docs contain no personal absolute paths, private service
  endpoints, credentials, or authorization values.
- [ ] README, CHANGELOG, release notes, and API inventory are rechecked against
  the final candidate SHA.

## Live qualification scope

- [ ] SAI-068 remaining live cases are either executed with current explicit
  authorization or recorded as `BLOCKED_CONFIGURATION`, `BLOCKED_PLATFORM`,
  `BLOCKED_INFRA`, `NOT_EXERCISED`, or outside the RC.2 guarantee. Previously
  passing cases are not repeated without reason.
- [x] Fixture, hosted CI, Host integration, and live-service evidence remain
  separate claims.

## Gate

The allowed final result is `READY_FOR_RC2_TAG` only after all hard evidence is
green and all remaining live gaps are explicitly scoped. Otherwise the result
is `BLOCKED_RC2` with the smallest concrete blockers listed in the parent
project's SAI-073 record.

This checklist does not create a tag, GitHub Release, package publication, or
merge to `main`.
